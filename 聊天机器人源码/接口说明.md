# 接口说明

> 适用版本：聊天机器人 v1.1（OneBot 接口版，已移除内置 NapCat 运行时）
> 源码根目录：`D:\CHAT\源码`

本文档说明程序对外/对内的接口契约，方便二次开发、替换接入方式或编写插件。

---

## 1. 总体结构

```text
main.py                     程序入口 / CLI / 运行时装配
  └─ src/core/pipeline.py   消息主流程（白名单、频率、安全、AI、记忆、发送）
       ├─ src/integration/  平台接入适配器
       │    ├─ wechat.py    微信：本地数据库 + hook HTTP 接口
       │    └─ qq.py        QQ：OneBot v11 正向 WebSocket
       ├─ src/ai/           回复生成器（OpenAI 兼容 / DeepSeek）
       ├─ src/core/interfaces.py  核心抽象接口
       ├─ src/policy/      白名单、频率策略
       ├─ src/security/    注入检测、隐私检测
       ├─ src/memory/      按人摘要、分层记忆、账本
       └─ src/web/         联网检索、抓取、引用
```

主流程只依赖 `src/core/interfaces.py` 里的抽象接口，接入层、AI、策略、表情包均可替换。

## 2. ChatAdapter（平台接入接口）

位置：`src/core/interfaces.py`

```python
class ChatAdapter(ABC):
    platform: Platform

    def set_on_message(self, callback: Callable[[Message], None]) -> None
    def start(self) -> bool
    def stop(self) -> None
    def available(self) -> bool
    def send_text(self, chat_id: str, text: str) -> bool
    def send_image(self, chat_id: str, image_path: str) -> bool
```

### Message 关键字段

位置：`src/core/models.py`

```python
Message(
    platform: Platform,        # WECHAT / QQ
    chat_id: str,              # 会话 ID：wxid / 群 ID / QQ 号 / QQ 群号
    chat_name: str,
    is_group: bool,
    sender_id: str,
    sender_name: str,
    content: str,
    mentions_me: bool,         # 是否 @ 了机器人
    timestamp: float,
    message_type: MessageType, # TEXT / IMAGE / VOICE / OTHER
    image_paths: list[str],    # 本地图片/表情路径（可为空）
)
```

### 2.1 微信适配器

位置：`src/integration/wechat.py`

- 读消息：`wechatauto` 读取本机已登录微信的本地数据库（纯本地读盘）。
- 发消息：通过本机注入 hook 的 HTTP 接口，默认 `http://127.0.0.1:30001`。
- 默认**不启用屏幕自动化**：`config.wechat_screen_send = false`，不模拟鼠标/键盘。
- Hook 接口（内部实现，不保证跨版本稳定）：
  - `GET /QueryDB/status`
  - `POST /QueryDB/execute`（只读 SQL）
  - `POST /SendTextTo`
  - `POST /SendImgMsg` / `POST /SendImageVirtual2`
  - `POST /EmojiSendDataTo` / `POST /EmojiSendMd5To` / `POST /EmojiPinned`
- 需要外部提供 `hook/wxhook415.dll`（本程序不负责生成/破解）。
- 相关配置：`wechat_hook_enabled`、`wechat_screen_send`、`wechat_auto_inject`、`wechat_minimize_lock_input`。

### 2.2 QQ 适配器（OneBot v11）

位置：`src/integration/qq.py`

- 连接方式：**OneBot v11 正向 WebSocket**。
- 配置项：`config.json → qq_onebot_ws_url`，默认 `ws://127.0.0.1:3001`。
- 程序**不再内置 NapCat**，也不会启动/管理 QQ 或 OneBot 实现；需要外部先运行兼容 OneBot v11 的实现并登录 QQ。
- 使用的事件：`message`（私聊/群聊）。
- 使用的 API action：
  - `send_private_msg`：`{"user_id": ..., "message": "..."}`
  - `send_group_msg`：`{"group_id": ..., "message": "..."}`
  - `get_login_info`：获取机器人自身 QQ，用于 @ 判定
- 图片/表情发送：以 CQ 码 `[CQ:image,file=本地路径]` 发送。
- 连接失败会每 5 秒重连；发送超时不会盲目重试，避免重复消息。

## 3. ReplyGenerator（AI 回复接口）

位置：`src/core/interfaces.py`、`src/ai/deepseek.py`

```python
class ReplyGenerator(ABC):
    def generate(
        self,
        system_prompt: str,
        style_instruction: str,
        history: List[dict],
        user_message: str,
        images: Optional[List[str]] = None,
        thinking: Optional[str] = None,       # "enabled" / "disabled"
        reasoning_effort: Optional[str] = None,
        max_tokens: Optional[int] = None,
    ) -> str
```

- 默认实现：DeepSeek/OpenAI 兼容接口，`POST {base_url}/chat/completions`。
- 配置项：`config.json → wechat_ai / qq_ai`：
  ```json
  {
    "api_key": "",
    "base_url": "https://api.deepseek.com",
    "model": "deepseek-chat",
    "system_prompt": "..."
  }
  ```
- 支持多模态图片：`images` 非空时，`content` 为 `text + image_url` 数组。
- 思考强度：普通闲聊 `disabled / 300`；兴趣话题 `enabled / low / 1350`；硬任务与联网 `enabled / high`。

## 4. 策略与安全接口

位置：`src/core/interfaces.py`

- `WhitelistPolicy.is_allowed(message) -> bool`：白名单硬规则。
- `FrequencyPolicy.should_reply(message) -> bool` / `on_reply_sent(message)`：
  - 按时间间隔、按条数、仅 @ 时回复。
- `SecurityDetector.detect(message) -> Optional[str]`：
  - 注入检测、隐私刺探检测；命中后告警，隐私事件不回复。

## 5. 插件接口

位置：`src/plugins/api.py`、`src/plugins/loader.py`

### 目录结构

```text
mod/<插件名>/
├─ plugin.json   # {"name", "title", "description", "version"}
├─ plugin.py     # class Plugin(PluginBase)
└─ config.json   # 插件自己的 API 配置（可选，自动生成）
```

### 接口

```python
class PluginBase:
    name: str
    title: str
    description: str
    version: str
    api_defaults: Dict[str, str]   # api_key/base_url/model

    def bind_dir(self, plugin_dir: str) -> None
    def load_api(self) -> None
    def save_api(self) -> None
    def build_content(self, parent) -> None  # 构建插件 UI
    def on_start(self) -> None
    def on_stop(self) -> None
    def check(self) -> tuple[bool, str]
```

### PluginContext

```python
PluginContext(
    config=..., config_store=..., bus=..., queue=...,
    adapters={Platform.WECHAT: ..., Platform.QQ: ...},
    memory_store=..., data_dir=..., mod_dir=..., napcat=None,
)
```

- `context.napcat` 仅为兼容插件接口保留；主程序已不再启动/管理 NapCat。
- 插件加载失败会自动跳过，不影响主程序。

## 6. 记忆接口

位置：`src/memory/`

- `ContactMemory`：按联系人摘要，方法包括 `summary(chat)`、`write_summary(...)`、`update_summary(...)`、`build_context(...)`。
- `HierarchicalMemory`：3 天窗口 + 同级合并（`Hierarchy`）。
- `Ledger`：只追加账本，记录回复/表情/摘要/联网/配置变更。
- 记忆目录：`memory/wechatMM/`、`memory/QQMM/`（默认隔离）。

---

## 7. 配置接口

位置：`config.json`（exe 同级；源码运行时为项目根）。

主要字段：

| 字段 | 说明 |
|---|---|
| `wechat_ai` / `qq_ai` | API Key、Base URL、模型、System Prompt |
| `whitelist_enabled` / `whitelist` | 白名单开关与会话列表 |
| `frequency_strategy` / `frequency_value` | 回复频率策略与参数 |
| `wechat_enabled` / `qq_enabled` | 平台启用开关 |
| `qq_onebot_ws_url` | OneBot v11 WebSocket 地址 |
| `emoji_enabled` / `emoji_images_dir` | 表情包开关与图片库目录 |
| `memory_max_messages` / `memory_compact_*` | 记忆压缩阈值 |
| `web_*` | 联网检索开关、引擎、限额 |
| `reply_split_*` | 长回复分段设置 |
| `wechat_hook_enabled` / `wechat_screen_send` | 微信 hook 发送、屏幕自动化开关 |

## 9. 扩展方式

1. **换平台**：实现 `ChatAdapter` 并注册到运行时适配器；
2. **换模型**：实现 `ReplyGenerator`（OpenAI 兼容接口即可）；
3. **加功能**：写 `mod/<插件>/plugin.py`，通过 `PluginContext` 拿配置/事件/适配器；
4. **改策略**：实现 `WhitelistPolicy` / `FrequencyPolicy` / `SecurityDetector`。

---

## 10. 注意

- 本项目不是腾讯/QQ 官方产品；微信 hook 与 OneBot 接入均属第三方方式，存在账号风险。
- 不要把 `config.json`（含 API Key）发给别人；发布包里的 `config.json` 是空 Key 模板。
- OneBot 实现需自行准备并保证版本兼容；程序只负责连接 `qq_onebot_ws_url`。
