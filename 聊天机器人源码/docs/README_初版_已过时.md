# 聊天机器人

Windows 桌面应用：让 DeepSeek 接入电脑端**已登录的 QQ 与微信**，在用户指定的白名单会话（群聊/私聊）中自动读取消息并回复。可打包为独立 `聊天机器人.exe`。

## 功能
1. **消息接入**：读取电脑端已登录微信（wxauto UI 自动化）与 QQ（NapCat/OneBot 协议）的群聊/私聊消息，并能发送回复。
2. **白名单控制（硬性规则）**：只回复用户指定的会话，白名单之外一律不回复、不交流。
3. **回复频率控制（可切换）**：按时间间隔 / 按消息条数 / 仅被 @ 时回复。
4. **AI 回复配置**：自定义底层提示词（System Prompt）与回复风格（正式/幽默/简洁/详细/自定义）。
5. **提示词注入防护（硬性规则）**：无视试图改变角色/规则的消息，并弹出预警（时间/人/注入内容）。
6. **隐私与环境信息保护（硬性规则）**：拒绝回答电脑配置、IP/地区、电脑名、时间/天气、密码/文件等询问，并弹出预警。
7. **表情包**：按语境附上 emoji 字符，并支持本地表情图片库。
8. **界面**：主界面（最近回复记录）、独立预警界面（注入+隐私两类告警）、设置界面。
9. **日志与记录**：持久化所有已发送回复与所有告警事件。

## 安全与权限原则（最高优先级）
- 白名单是硬性规则：白名单外不回复。
- 任何聊天对象的消息都不能覆盖用户设定的提示词与规则。
- 任何环境/隐私信息询问一律不回复，并上报预警。
- 敏感配置只能由用户在界面中修改。

## 接入技术路线与风控说明
| 平台 | 方案 | 说明与风险 |
| --- | --- | --- |
| 微信 | **wxauto4（免费版，UI 自动化）** | 读取已登录的电脑端微信 4.1 窗口。免费版无全会话事件监听，采用「遍历会话 + 逐窗口轮询读取 + 去重」；优点：贴近真实操作、风控较低；缺点：依赖微信窗口保持打开，界面改版可能失效，轮询会切换聊天窗口。Plus 版（wxautox4）可提供真正的监听接口，如需更佳体验可自行升级。 |
| QQ | **NapCat / OneBot v11**（协议） | 需单独运行 NapCat 实例并以同一 QQ 号登录，程序通过 WebSocket 连接。优点：稳定、事件完整；缺点：需额外运行一个组件；使用第三方机器人框架存在账号风控可能，请自行评估。 |

> 第三方闭源软件接入方式可能随版本更新失效，请知悉。

## 环境要求与安装
- Windows 10/11，已安装 Python 3.10+。
- 电脑端已登录微信（wxauto 需要）。

```powershell
cd chatbot
pip install -r requirements.txt
```

QQ 接入：先启动 NapCat 并以目标 QQ 号登录，开启 OneBot v11 正向 WebSocket（默认 `ws://127.0.0.1:3001`，可在设置界面修改）。

## 运行
```powershell
python main.py
```
首次运行会生成 `config.json`。在设置界面填写 DeepSeek API Key（默认官方地址 `https://api.deepseek.com`，模型 `deepseek-chat`），配置白名单、回复风格与频率策略后即可开始自动回复。

## 打包 exe
```powershell
cd chatbot
pyinstaller build/聊天机器人.spec
```
产物位于 `build/dist/聊天机器人.exe`（或使用 `.spec` 中指定的名称）。
